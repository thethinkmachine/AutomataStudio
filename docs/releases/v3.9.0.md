## What's Changed

### Fixed
* **Constructions and generated code now read the wildcard edge.** An edge on `Σ` (any symbol) was followed when you ran a machine, but ignored by NFA → DFA, ε-NFA → NFA, DFA Complement, DFA Minimize, the product construction (union, intersection, equivalence) and every code generator. Each could give a machine, or a program, for a different language than the one on the canvas. If you used any of these on a machine with a `Σ` edge, run it again.
* **DFA Minimize gives the minimal DFA when a move is missing.** A state with no move on a symbol was always kept apart from one that moves to a dead state, so some results had a state too many. The language was right; the size was not.
* **Is Empty? and Is Finite? ask for a finite automaton.** They answered for a pushdown automaton or a Turing machine by looking at the diagram alone, which does not decide either question there.
* **A PFA rejects a word whose probability is exactly the cut-point.** Rounding could put it a hair above: weights 0.1 and 0.2 at a cut-point of 0.3 accepted, under a trace reading "0.3 > 0.3".
* **Greibach normal form no longer runs out of memory.** A grammar with a symbol that derives nothing could freeze the page. Such symbols are removed first, and a conversion that passes 5,000 rules stops and says so.
* **A backwards regex bound or range is an error.** `a{3,1}` was read as `a{3}` and `[c-ab]` as `[b]`, without a word. A regex whose bounds multiply out to more than 20,000 symbols is refused instead of freezing the page.
* **Copy and paste keeps accepting states accepting.**
* **A state cannot be renamed onto another state's name,** and an exact copy of a transition cannot be added.
* **Reverse on an edge is refused when it would break determinism** on a Turing machine or a pushdown automaton, as it already was on a DFA.
* **What you delete is no longer selected.** A state or transition deleted from its menu stayed in the selection, where Delete and Copy went on acting on it.
* **The batch tester agrees with itself.** A line it could not read was drawn as failed under a summary reading all passed; a transducer line read "undefined, as expected"; and Run on an empty box left the last results up.
* **Library pages with a very large machine open again.** Any page listing a machine too large to sketch failed with "h is not a function". A link to a machine that is no longer in the library lands on a page with a search and a way back, and an empty filter group no longer prints "null".
* **Text with a `<` in it is shown as text.** A symbol such as `<b>`, or a word typed into the run box, was read as markup in the trace log.
* **Typing with an input method.** Pressing Enter to pick a Chinese, Japanese or Korean candidate no longer submits the dialog or runs the field.
* **StateMate.** A reply with an enormous alphabet or name, or a name that is not text, is refused rather than drawn. A request the provider rejected as malformed no longer offers a Retry that can only fail. An error can no longer show the key of an address that failed to parse. Google AI Studio's key hint is `AIza`.

### New
* **A result says when it is out of date.** Edit the machine after a run or a batch test and the verdict, the trace and the rows dim, with "machine changed — run again" in the section's header. Undo the edit and they are current again. Moving or renaming a state marks nothing.
* **The Algorithms list works from the keyboard.** Tab to an algorithm and press Enter or Space.

### Desktop app
* **Tighter file access.** The app's own pages could be made to load files from folders beside the app's, the window could be navigated to another page that kept its file access, and a save in place went to any path. Each is closed: nothing outside the app is served, the window stays in the app (web links open in your browser), and a save in place goes to `.automaton` and `.json` only.

### Command line
* **`automata … | head` ends quietly** instead of with an `EPIPE` stack trace.
* **A mistyped flag is named, with the one you probably meant:** `unknown option --limt. Did you mean --limit?`
* **A path that cannot be opened is a sentence,** not Node's error text.
* **`automata check-proof -` reads a proof from standard input.**
* **A command waiting on the keyboard says so,** rather than looking hung when it was given no machine.
* **The MCP server answers `initialize` with a protocol revision it supports,** instead of repeating whatever the client sent.
