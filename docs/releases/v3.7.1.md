## What's Changed

Saving in the desktop app is now safe for the file you are saving over.

### Fixed
* **Files from other programs are no longer overwritten.** Opening a JFLAP file, a PNG with a machine inside it, or a statechart and pressing Ctrl+S used to save over the original in this app's format, so the JFLAP file stopped opening in JFLAP and the PNG stopped being an image. These files now open as a new, unsaved machine named after the file, and the first save asks where to put it.
* **A crash while saving can no longer leave a broken file.** The new version is written in full first and then swapped in, so a crash, a power cut or a full disk leaves you with either the old file or the new one.

### New
* **The previous version is kept** next to the file as `name.automaton.bak`, so a save you regret can be undone.
* **Changes made outside the app are protected.** If the file was changed by another program, a sync service or `git` since you opened it, or was moved or deleted, Save asks before overwriting it.
* **`automata test --watch` follows editors that save by replacing the file**, such as vim, on macOS and Linux. It used to stop rerunning after the first such save.
