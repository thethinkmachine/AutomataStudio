## What's Changed

### Improved
* **States are redrawn, and every mark means one thing.** The ring around a state used to mean several things at once. Green meant the start state, but also "edges leave here" when you highlighted a state's outgoing edges, and two meanings at once drew mismatched rings. Now:
  * **What a state is** has its own mark. The start state has its arrow, an accepting state has a gold inner ring, a Moore state shows its output under a short line, and a parity priority sits in a badge on the rim (filled when the priority is even).
  * **What is happening to it** (hovered, selected, on the run's current step, rejected, highlighted) changes only the outer ring and the fill. So a selected accepting state still reads as accepting.
  * **Selection is purple**, as it is for edges and notes.
* **State names read like a textbook.** `q0` is drawn as q₀ and `q_even` as q with "even" below. Long names shrink to fit inside their circle instead of running over it. The formal definition uses the same names.
* **The formal definition is shown whole.** It used to be cut off after a few lines, hiding F and δ on a PDA or a Turing machine. It now grows to fit and is set at the panel's size.
* **Cleaner side panels.** Section titles are plain words with their symbol (Alphabet Σ, States Q, Transitions δ), counts of zero are no longer shown, and both panels label things the same way.
* **The toolbar opens at the bottom left** of the canvas, out of the way of the diagram. If you have moved it, it stays where you put it.
* **Open a file from the start screen.** The empty canvas has an **Open file** button next to the examples.

### Fixed
* **The playback speed knob is no longer cut off** in the Run tab on a narrow panel or a long run. The controls make room by dropping the speed's "1×" label first; the knob still shows the speed, and its tooltip gives the number.
* **The keyboard focus ring on the step buttons is drawn whole** instead of as two thin bars.
