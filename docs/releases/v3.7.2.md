## What's Changed

### Fixed
* **Closing a tab no longer loses edits that were never saved to its file** (desktop app). Autosave used to clear a tab's unsaved dot even though its file on disk still had the old version, so closing the tab asked nothing and those edits were lost. A tab opened from a file now keeps its dot until the file itself is saved, and **Save** in the close prompt writes the file.

### New
* **The app notices when an open file changes on disk** (desktop app): edited in another program, updated by a sync service such as Dropbox or OneDrive, or changed by `git pull`. A bar appears on that tab with two choices:
  * **Reload** brings in the version on disk. Ctrl+Z undoes it, and you are asked first if the tab has changes the file does not.
  * **Keep mine** keeps what is on the canvas, and your next save replaces the outside change.

  If the file was moved or deleted, the bar offers **Save As…** instead. The app checks when its window comes back into focus, and as soon as the file changes.
* **Less work lost in a crash** (desktop app and website). Your edits are now kept about a second and a half after you stop, rather than up to 15 seconds later, so a crash or a power cut costs far less. Very large machines keep the longer interval, since saving them often makes the canvas stutter.
